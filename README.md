# Find Your People (v2)

A full-stack web application designed to help users connect, create events, and join local communities. 

**Live Demo:** [Find Your People](https://find-your-people-v2.vercel.app)

---

## 🛠 Tech Stack

**Frontend:**
* React 19 (built with Vite)
* Axios for API requests
* Deployed on [Vercel](https://vercel.com/)

**Backend:**
* Node.js & Express.js
* CORS & Dotenv for configuration
* Deployed on [Railway](https://railway.app/)

**Database & Authentication:**
* [Supabase](https://supabase.com/) (PostgreSQL & Supabase Auth)

---

## ✨ Features

* **User Authentication:** Secure sign-up and login via Supabase Auth.
* **Community Feed:** Browse a real-time feed of events and posts.
* **Event Creation:** Authenticated users can create and publish new community events.
* **Interactive Participation:** Users can toggle joining or leaving events directly from the dashboard.
